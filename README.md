# ✈️ Airline Price Prediction Using Machine Learning

## Project Overview
- Developed a machine learning regression model to predict airline ticket prices based on flight details.
- Performed data preprocessing, feature engineering, and exploratory data analysis (EDA) to prepare the dataset for modeling.

## Key Features
- Cleaned the dataset by identifying and handling missing values.
- Extracted journey day and month, departure and arrival hours, and minutes from date/time features.
- Converted flight duration into numerical hour and minute features.
- Encoded categorical variables using One-Hot Encoding and Label Encoding.
- Analyzed airline-wise ticket prices and route-based price distributions using visualizations.
- Handled high ticket-price values using a median-based replacement approach.
- Split the dataset into training and testing sets for model evaluation.
- Implemented Linear Regression and Random Forest Regression for price prediction.
- Evaluated model performance using Mean Squared Error (MSE), Mean Absolute Error (MAE), and R² score.

## Technologies Used
- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Development Environment:** Jupyter Notebook
